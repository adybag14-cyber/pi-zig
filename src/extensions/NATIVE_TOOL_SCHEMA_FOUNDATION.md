# Native tool schema and format foundation

Authority is the clean built Pi reference at `1cedd32724abfcb0915f76cc61b6827e2c16dbad`, using the installed locked dependency TypeBox **1.3.27**. Pi durable itself is 1.1.0. The reviewed later Pi source head has no durable/Chord/environment changes. Original executable captures are external under `pi-zig-update-evidence-20261003/env-completion-20261007`; no source JavaScript implementation is installed in this repository.

This additive foundation extends the qualified68 runtime layer:

- The existing fourteen native TypeBox constructors now retain source hidden `~kind`/`~optional` descriptors, object property identity, Optional deep-copy behavior, symbol annotations and original getter exceptions. Record creation preserves exact string/number/integer patterns, finite literal/boolean keys, raw union behavior, and the tested distributed primitive intersections. Installed named/default Type namespaces use real ESM namespace objects and source function names/arities.
- Native argument cloning preserves shared and cyclic objects, arrays/holes, undefined and special numeric values, BigInt, Map/Set, Date, RegExp, typed-array/buffer aliasing and original getter exceptions. It is a private workflow helper; this does not advertise complete Node structuredClone support for transfers or every host class.
- `native_tool_validation.zig` is a private native evaluator with original ordered error messages, local JSON-pointer references, logical branches, conditional/dependent rules, contains/count rules, tuple prefixes, Unicode constraints and evaluated key/item tracking. Its original-source capture covers thirteen grouped schema cases. It is not yet installed as the public pi-ai validation module; compiler caching, full coercion, extended reference/refinement behavior and the remaining malformed-schema matrix continue separately.
- The TypeBox format module implements all twenty-one pinned default formats, including source normalization, punycode, bidi/contextual IDN rules, encoded label limits, Unicode IDN email, leap seconds and URI/IRI edge behavior. The source matrix covers 903 string-format comparisons and 168 nonstring coercion/error-category comparisons. Registry tests retain callback/return/error identity, detached entries, default ordering and reset behavior. Format/default bindings are actual readonly ESM namespaces, with source descriptors and function metadata.
- Native `tools/typebox_format_patterns.zig` extracts fifty exact regex declarations without evaluating source JavaScript. Generated data records SHA256 for every source format file and requires package version 1.3.27. Regenerate with `zig run tools/typebox_format_patterns.zig -- <locked-typebox-package-root> src/extensions/typebox_format_patterns.zig`; append `--check` for deterministic comparison. Preserve generated bytes and the MIT attribution in `TYPEBOX_LICENSE.txt`.
- Harness reporter handling follows source null-coalescing; omitted report/memo/task arguments reject safely or report undefined as appropriate, rather than indexing an empty native argument slice. Source captures check both null and functional reporters.
- Native ESM namespace creation uses a portable one-function C ABI adapter and the real QuickJS module linker/initializer. It does not evaluate a JavaScript namespace shim.

GPA allocation-failure coverage exercises Record ownership, cyclic argument cloning/buffers, evaluator contexts/errors/regex resources, and format registry/IDNA/punycode resources. Windows builds retain the vendored static SQLite default. Source-format and binding gates do not add global PATH changes or copied DLLs.

The unfinished `native_tool_coercion.zig` continuation is excluded from the frozen foundation snapshot. Public `validateToolCall`/`validateToolArguments`, real Generation/Tool/Compaction workflows and public `createRegistry` remain pending. Full durable/Pi parity is not certified by this foundation.
