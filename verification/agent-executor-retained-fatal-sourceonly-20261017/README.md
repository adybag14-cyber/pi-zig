Source-only successor to 1138b9cfc7d009e3302ac8cb6051fbeda1051b93. The old 1ec, 802 and 1138 packets remain immutable negatives for this newly identified constructor-priority case.

A real user-selected Promise subclass may call super(executor), consume the native executor exception into its rejected Promise, and then throw an ordinary reason. Engine.captured_exception is mutable diagnostic state; checking it only after successful construction cannot preserve the first callback event. A later successful native callback can also replace that diagnostic slot.

The actual lifecycle now allocates a private native holder before creating its executor. The executor roots both the existing Source resolve cell and this holder. On its own failed write, it retains the first exact direct native allocator failure or freshly private-tagged allocation reason qualified at that write boundary. Storing the reference requires no allocation. Historical private tags and marked untagged data are not new trusted events. The holder is private native state with a GC mark and finalizer; a custom constructor retaining the executor also retains its holder safely.

Protected construction calls the actual global constructor once. Before checking either its return value or exception, it checks that independently owned first callback event. It takes pending/captured values out of their mutable slots, releases the constructor result and displaced ownership with pending cleared before each release, then restores the exact first reason to the AF error path. No later ordinary constructor result, native diagnostic write, or later native allocation failure replaces that retained reason. No Engine/C/shared callback or general Promise policy changes are made.
