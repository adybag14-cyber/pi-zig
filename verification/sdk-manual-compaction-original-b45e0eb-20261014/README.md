This job captures the actual b45 upstream ordinary compaction methods twice on
Linux and macOS. It uses the complete immutable Source checkout, official export
mapping, pinned lockfile dependencies and official catalog hydration with the
same historical typed metadata as the Windows capture. Generated catalog
freshness remains a separate application gate.

The input is byte-identical to the Windows44 corpus. The package directory is
an explicit caller environment input, `/owned/pi-package`, on these POSIX jobs.
All44 raw observations must match between the two captures. The43 cases without
the platform-specific missing-model documentation path must also match Windows.
The remaining case is retained in full; it is not removed from the corpus or
replaced with Windows output. Its genuine POSIX output will be used by native
platform tests with the same package-directory input.

Source/dependency/Node/candidate manifests and observed module hashes are
verified before and after each bounded capture. This does not activate the
native factory or certify the complete application.
