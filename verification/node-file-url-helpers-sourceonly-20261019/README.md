# Genuine Node file-URL path helpers — source-only unit

This unit implements the selected Node 24.13.0 internal/url bodies isURL,
fileURLToPath and toPathIfFileURL, their actual error families, and the private
cross-realm RegExp operation consumed by the Windows path. It is the URL
dependency for the classic realpath caller. Public URL namespace publication
and the classic caller are separate integration steps.

## Implemented owner chain

The real process/Stream and argument-error bootstrap supplies the existing
TypeError, inspector, assertion and kIsNodeError marker. The argument owner
retains original Reflect.apply and Array.prototype.unshift for later error
families. Its five exports and the bootstrap's seven returned values keep
their existing ABI. The new string-message class uses the real VM rest-array
producer, captured unshift, live internal inspect.format and actual current
lexical superclass with the original new.target.

The path owner retains the actual native URL constructor/decoder, frozen
empty options, platform and captured string methods. Structural URL predicates
perform live Source property reads. The Windows slash replacement uses the
same real SafeWeakMap and internal RegExp realm, with original intrinsic flag
getters and the actual private Symbol.replace method. No guest source body,
public Module facade or replacement URL/RegExp/error constructor is supplied
to production.

All guest-capable operations use the canonical Node pending/current-event
boundary and owned completion. Successful private or flagged values remain
DATA; actual current fatal provenance is checked before later work. Direct
non-guest allocations keep their separate producer checks. Captured lexical
values and immediate predicate temporaries retain their actual Source
retirement boundaries.

- Nineteen declared native controls: thirteen shared Node observers and six

- Source entrypoint: node-source-observer.mjs under pinned Node 24.13.0 with
  --expose-internals, only under Root's separate execution grant.

The shared observers cover structural reads and short circuits, option/getter
order, repeated toPath gating, captured URL/decoder, actual path errors,
encoded separators, UNC/domain handling, private RegExp coercion, primitive
Symbol inputs, genuine class/rest/formatter/new.target behavior and eager
function-message conversions. Native controls inspect the same complete
owner identities, sole predicate retirement, a live windows lexical value,
actual fatal producer identity/no later guest progress, ordinary private
DATA, successful flagged DATA, and a later error-family acquisition after
the original argument primordials have been poisoned.

No Node capture, native compilation, metadata discovery or runtime execution
has been performed for this source unit. Declaration counts are authored
counts. Source peers are bounded reviews, not runtime acceptance.

## Remaining integration boundaries

The actual url_parser domain backend is reused. Its explicit unsupported
IDN-context path remains a backend gap; it is not converted into a successful
domain result. Complete WHATWG URL/IDNA and public URL profile parity are
outside this selected path-body unit. The genuine full Node bootstrap must
capture these primordial owners before guest execution. Public filesystem
and Module/Jiti wiring must consume the same complete owner identities.
