# Private compiler pass ownership and cancellation

SOURCE ONLY successor to immutable a254898d. No builds, parser/AST/formatter, generators, Node, native execution or metadata query ran. Root authorized the concrete opt-in ownership fix after the actual unsafe failure paths were reported. NULL-context legacy semantics/selection remain unchanged.

The private compiler scope disables peephole code_match/code_has_label matching, jump threading and dead-code removal in the actual variable and label passes. This keeps actual original instructions and atom ownership available during failure; mandatory scope/variable translation, labels, jumps, widths/relocations, source positions and actual VM stack analysis still run. The returned value remains an actual VM ordinary function. Language evaluation/strictness/realm/closure semantics do not use a synthetic wrapper. The deliberate tradeoff is larger unoptimized bytecode and compile/run cost; tail-call/drop/constant/jump-chain peephole savings are not promised in this private compiler. The legacy NULL diagnostic path retains its prior optimization behavior.

`resolve_labels` now polls actual instruction, mapped-argument, relocation, label, jump-shrink/index-repair and source-location encoding loops. Relocation heads advance before releasing processed native nodes, so failure cleanup retires only the remaining chains, once. Output native bytecode borrows input atom references until successful commit; on interruption it is freed as native storage only and the original FD still owns the operands. Existing frees of predefined length/empty-string atoms are constant-atom no-ops; dynamic-atom-removing matches are disabled. A pending/error check precedes post-pass patching. Metadata cleanup fields are initialized before any new failing poll. No failing polls run during retirement.

The preceding actual variable pass had a related failure path: it tried to copy the unprocessed tail using fallible allocation after a reason was already pending. The private pass now uses actual atom operands as an internal transfer ledger. A complete unchanged instruction is reserved and copied before its input atom operand is cleared to JS_ATOM_NULL; explicit scope-name releases also clear their exact input operand. A negative scope resolver result is checked before releasing that still-owned input name. Generated atom operands reserve their complete four bytes before duplicating the reference at 27 actual semantic emission sites. Optional-chain opcode conversion uses the same complete instruction transfer. Failure frees only output-owned atoms/native storage; the original FD owns all uncleared operands and is destroyed normally, without allocating a tail copy. Success retires any remaining original operands before committing the real output bytecode. The two CodeContext instances initialize their private flag explicitly; no flag reaches runtime/serialized bytecode.

The actual parser byte emitters now stop after an already pending failure or failed buffer inside this scope. They do not append a later operand after an earlier failed opcode/operand, and do not invent a new OOM from an allocation that was not attempted. Existing producer-level allocation/stack/interruption/capacity status and first-reason ownership remain unchanged.

Two new named causal declarations (41 source declarations total, actual metadata unknown) use a genuine 512-branch input with distinct property/literal atoms, mandatory jumps, loop branches and try/finally. One measured native allocator sweep checks real atom_count after releasing every unexpected/result/reason owner and GC, then requires a healthy real compile/execution of the same input to return 42; all native allocations must retire at runtime teardown. A second baseline measures the real existing 10000-cadence native interrupt callbacks (bounded 1..128), then fresh-runtime attempts leave an exact pending object at each measured callback. Each failure requires operational NONE, exact first reason, no body/jobs/load, restored atom_count and healthy compile/execution. No phase/PC/refcount/parser result is injected. The finite source review still must verify each actual ownership producer; declarations and static callsites are not execution proof. Allocator admission remains at most 512 measured native events. Larger measurement is an explicit negative, not an unbounded sweep.

The original 98954 and a254 manifests/commits are retained historical scopes. Native Unicode/libc/copy/cleanup atomic boundaries from the regexp implementation remain explicit; this delta does not turn them into instruction-level interruption. Fixed-capacity native lexical/lookup scans and recursive parser stack frontiers still require the final finite combined compiler review. SourceMap/sourceURL/code-cache metadata, full wrapSafe/load-ESM policy, jiti/bootstrap/default selection and C union qualification remain separate real dependencies. This is implementation preparation, not whole Node24/V8 equivalence or permission to execute.
