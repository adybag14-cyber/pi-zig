# Direct C explicit-receiver Get prerequisite

Root authorized this separate inert C/H ABI proposal. The active C and header remain unchanged. `receiver-get-prerequisite.patch` adds only a directly linked `JS_PiGetPropertyReceiver(ctx, base, atom, receiver)` wrapper and declaration. It invokes QuickJS-NG's actual existing static `JS_GetPropertyInternal(ctx, base, atom, receiver, false)`, the same internal operation used by its interpreter super-property opcode and Reflect.get. No JavaScript bridge, Reflect/global lookup, descriptor walk, proxy approximation, prototype mutation, atom conversion or error classification is added in C.

Base, receiver and atom are borrowed; the result is owned and can be the real exception marker. The caller owns/retires its atom and preserves actual pending/owned reason precedence at its native boundary. Accessor this, Proxy get target/key/receiver, fallback, invariants, null base and raw reasons are handled by the actual VM. The shim neither clears exceptions nor marks an arbitrary value fatal. Existing trusted native callback policy remains the caller's responsibility. The adapter's private superGet resolves the live superclass prototype and calls this exact prerequisite ABI; no Proxy super-base approximation remains in that selected source.

Four named native controls are prepared in `src/native_chord_sqlite_receiver_get_test.zig`: actual ordinary accessor receiver/live-base replacement, actual Proxy get trap arguments, raw ordinary getter/Proxy throws without diagnostic coercion, and real success-with-pending ordinary/private-tagged native callbacks. They use genuine VM getters/proxies and the real proposed C operation, not a Cloudflare storage stand-in. The controls test the raw shim's ownership/identity; trusted caller fatal marking remains a separate adapter boundary. No expected fixture, observed output, compilation, parser/AST check, metadata or execution exists. The root is unregistered; an eventual separately reviewed build target must bind the actual linked C shim.
