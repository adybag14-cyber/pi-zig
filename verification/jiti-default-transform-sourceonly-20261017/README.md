Native default jiti transformer candidate, source-only/uncompiled/unrun. This
is a real native compiler path for an explicit consumed profile, not a custom
transform callback, identity function, default-Babel host or public selection.
It extends the existing reviewed module/type generator with native import.meta
passes and the ordinary default transformer result/options boundary.

native_jiti_default_transform.create(engine,Imports) returns an owned ordinary
function named transform, length1, with traced actual mlly/path imports. It
implements the default native result {code} for admitted inputs. Source option
preparation reads retainLines (including its conditional second read), babel
spread, interop/async/filename, JSX/TS phases and final plugin inspection in
order. Raw ordinary preparation failures remain raw. No Babel plugin object,
identity transformer or fabricated BABEL_PARSE_ERROR record is constructed.

Admitted consumption is the real outer transform's ordinary own-string-data
source option, empty Babel configuration, default retainLines:true, no JSX,
and the API12a readonly/named-import/default-function module grammar. Both
interop modes are valid for this named-only import subset; default/namespace
imports remain rejected. Actual TS erasure/module generation is reused, not
renamed as if it were the complete Babel options/result contract.

native_jiti_import_meta rewrites ordinary dotted read/call forms of .url,
.dirname, .filename, .env and .resolve. The first three use actual mlly/pathe
functions and source JSON.stringify ordering, or the original __filename/
__dirname/require('url') fallback. URL replacements run as a group before
dirname and filename, matching the pinned Program visitor. Env becomes real
process.env and resolve becomes the actual jitiESMResolve wrapper binding.
Computed, optional, bare, unknown and directly written/deleted meta forms fail
closed; env plus an existing source identifier named process is conservatively
rejected to avoid claiming unreviewed TS binding/elision interactions.

All syntax validation/code generation finishes before Module publication or
user execution. JSX/TSX, decorators, metadata extensions, resource management,
custom Babel options/plugins, maps, retainLines:false, inherited/accessor/non-
string source fields, malformed Babel diagnostics and the previous API12a
unsupported grammar are explicit frontiers. Rejections carry the native code
PI_UNSUPPORTED_JITI_DEFAULT_TRANSFORM, with an original compile-helper reason
as cause when appropriate. Trusted fresh host failures escape exactly and are
not disguised as an unsupported compiler input.

The pinned Babel pipeline's transformSync catch creates detailed Babel-derived
error markers. This candidate does NOT invent those diagnostics for syntax or
feature failures. The compiler's generated source formatting, public transform
code-byte parity, retain-lines/stack mapping and complete Babel behavior remain
unqualified. The genuine caller records complete original code for later byte
comparison; a mismatch is retained as a negative, never normalized into a pass.
No default assembly/cache selection or production factory is changed here.

Actual frontend integration must use its evaluateLowered boundary for the
already-generated body; re-running API12a lowering on this output is invalid.
