# Actual public tool truncation owner

Status: authored source only. No compiler, metadata query, native runtime or upstream Node capture has been executed for this unit.

The six exports selected by the frozen c268 public index are supplied by `native_sdk_public_truncation.create(engine)`: DEFAULT_MAX_LINES, DEFAULT_MAX_BYTES, formatSize, truncateHead, truncateLine and truncateTail. Ordinary function construction, default arity and one cached module identity are retained. This is a real public leaf owner; it does not claim to complete or activate the full coding-agent namespace.

The implementation uses the canonical AF33 guest boundary and C435 completion retirement through the catalog values adapter. Mutable Buffer, string and array methods are read and called in Source order; options retain JavaScript coercion. Head truncation keeps complete lines and its first-line lexical binding. Tail truncation preserves UTF-8 boundaries and the actual ToNumeric/increment behavior of a replaced Buffer owner. Expression roots retire before later getters, and the actual outcome is recorded before cleanup.

The install-only build target is `build-native-sdk-public-truncation`, selecting `SDK public truncation` from `src/native_sdk_public_truncation_test.zig`. Nine declared controls cover ordinary shape/cache identity, Unicode/newline/line-versus-byte behavior, live method and option ordering, BigInt cursor behavior, actual sole-holder retirement, ordinary private DATA, actual producer precedence, cleanup precedence and cancellation. Actual metadata, including imported storage tests, must be queried from the compiled artifact.

The original TypeScript bytes are archived in `public-truncation.c268.ts.txt`. The executable comparator preserves those function bodies with TypeScript-only syntax removed and formatting/comments normalized. Source and native functions both use the same genuine native Buffer module in these authored controls; a passing run would compare the truncation algorithms in the linked VM, not certify the upstream Node Buffer implementation or constitute an independent Node reference capture.

The existing actual native retirement hooks are reused from `native_sdk_initial_model_retirement_controls.zig`; no count transcript is injected. The holder-carrying method values are arrows so their retirement is not obscured by a constructible function/prototype cycle. No manual kept-object clearing is used in these controls.
