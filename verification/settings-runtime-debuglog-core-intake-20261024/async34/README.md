# Selected original JS async ID and stack declarations

This private source packet ports the complete selected ID/stack declarations from the retained Node async_hooks.js into the existing native Engine and Environment. It adds a 623-byte owned acquisition method for the Environment's real execution-resource array. The four other source/fixture additions contain the owner, a genuine Engine/Environment test fixture, 34 controls and a test-only reference assembled from 13 byte-exact original function bodies. Build composition adds only the retained 1,219-byte install-only insertion.

The private owner verifies the exact installed binding and the three shared view identities. It captures native fallback values once, preserves their undefined call receiver and argument order, and exports the captured clear function itself. It reads async_ids_stack live for every original statement. Push stores the resource before the overflow condition, preserves lexical offset during reentry, then performs the original individual assignments. Pop restores both IDs, completes and retires the live resource pop call, then commits stack length. Calling Environment.popAsyncContext as a JS fast-path shortcut would reorder those observable operations and is deliberately not part of this implementation.

State is charged, traced and retained by escaped callables; the Environment reference survives cache retirement. Current pending exceptions, actual native fatal producers and ordinary abrupt completions use the existing owned boundaries. Returned flagged data is not promoted to a fatal event. The source controls cover genuine shared backing, numeric fallback/growth, original-body differential observations, reentrant accessors, partial writes, exact error identity, cold pending/OOM and lifetime/GC.

The complete native async_wrap binding factory and its original fatal NumberValue/FromJust adapters are still required from bootstrap. The fixture's numeric bridge calls existing Environment methods, while unselected hook/check/exit policies explicitly error. It does not certify native exit behavior. Original active_hooks, emitAfterScript/fatalError, native TriggerUncaughtException/Message/exit and canonical process/timers assembly remain separate missing suppliers. This packet neither publishes async_hooks nor installs process._fatalException or diagnostics channels.

No Zig parser, formatter, native compiler, metadata query, runtime, Node reference or source generator ran. Only bounded source authoring, hashing, raw inverses, exact import resolution, review-patch reconstruction and read-only git apply --check were used.
