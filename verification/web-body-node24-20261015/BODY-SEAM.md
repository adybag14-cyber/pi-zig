# Shared Body seam, source-only

Response owns `native_web_response.zig` in the independent Root Response lane. This lane owns `native_web_body.zig`, WebIDL/Blob/File/FormData, Request and fetch integration. No new Body code is runtime-qualified yet.

`Streams` holds genuine Env `bindings` and `constructor` JS roots, plus private disturbed/errored/controller-close callbacks taking `(scope,bindings,value)`. `install(engine,streams)` retains/marks the supplied native graph. `require(engine)` fails explicitly while no real stream graph exists. The actual public Env constructor can itself serve as the binding root when adapters invoke Env's engine-owned private graph.

`Body` fields are `stream`, `source`, `length`, `content_type`, all JSValues. `extract(scope,interfaces,converted,keepalive)` returns Scope-owned values; facades duplicate/mark every committed field. `disturbed(scope,stream)` excludes locking. `unusable(scope,?Body)` tests locking then private disturbed state. `clone(scope,Body)` invokes actual public `tee()` and returns `Clone{original_stream,copy}` with Scope-owned fields. The facade commits the original replacement stream with duplicate/free and stores the duplicate copy in its new native instance.

`consume(engine,?Body,Mode,mime)` returns an owned native Promise. Modes are bytes/array_buffer/text/json/blob/form_data. Actual reader.getReader and the shared rooted-byte collector own consumption; reader locks are retained as Source does. Null bodies consume empty bytes without becoming used. JSON resolves actual global JSON.parse at EOF, as bundled parseJSONFromBytes does; QuickJS diagnostics remain actual QuickJS diagnostics. Unsupported multipart/async-iterable construction paths fail explicitly, with all176 captured expected rows preserved for later completion. MIME parameter serialization and complete multipart processing are pending.

The latter worker opt-in hunks are narrowly backported onto this baseline, without unrelated HTTP prepare/signing hooks or missing helper modules. Shared owner code and tests remain unqualified through this Body continuation.
