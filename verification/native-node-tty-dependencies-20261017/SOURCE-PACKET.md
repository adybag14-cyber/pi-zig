and scope helpers, canonical provider cache, shared completion owner, canonical
platform wake facade/Windows/Linux leaves/Linux mutex, and the same bounded CRT
close worker. It changes only the existing CRT ownership proposal and additive
Hub/frontend/worker readiness seams. Native owner_signal, Buffer, codecs, shared

The only Buffer differences in the old child tree are private-vs-public helper
visibility; Root's newer public helpers are preserved, never overwritten.

native_node_tty_dependencies exports the actual Socket/Hub/Scheduler/Wake/
ClosePool module/type aliases plus canonical.acquire. Instantiate the existing
TTY Assembly with those five exports, acquire one canonical Bundle using actual
streams/process, and pass &bundle.provider and bundle.net to the actual Inputs.
No stand-in type, second Pool instantiation or complete child graph is needed.

propagate_completion_errors behavior/comment. It adds Resource tag/poll/ref/

scheduler delegation delta keeps child/TTY using the same completion owner, but
the child scheduler/transport graph is NOT in the minimal TTY projection.

## Canonical constructor and ordinary class behavior

native_node_net_socket.createProvider(engine, actual_streams, actual_process)
creates the actual ordinary callable/constructible Socket, inheriting the real
Duplex constructor/prototype and initializing the SAME receiver by Duplex.call.
Provider.clone(engine) duplicates roots to that same constructor, state brand
and four-entry adopter registry. addHandleAdopter requires a known opaque brand,
VM-rooted owner/context and native resolve callback; resolve checks exact Engine
and actual handle. No fd/class-name/prototype rename is an admission capability.

native_node_net_socket_provider.acquire(engine, actual_streams, actual_process)
returns a stable per-Engine Bundle pointer with provider and net carrier. It is
rooted in the unregistered private native cache and returns the same pointer on
matching inputs. Mismatched dependencies are rejected. A native owner-thread
initialization guard prevents a getter from recursively publishing another
constructor. The cache owns charged native storage and marks/frees all VM roots.
Root's private-cache import guard is a retained prerequisite. The real exported
Socket and Stream aliases share the same constructor. No TCP/Server/connect
implementation or public node:net selection is claimed or manufactured.

TTY must pass &bundle.provider and bundle.net to its assembler. Public child
composition, if later selected, must pass this SAME provider through its actual
Inputs.socket_provider clone seam. Providers must not be separately recreated.
The cache itself does not register public modules or construct a TTY handle.

The synchronous hook consumes the WHOLE remaining byte span, with borrowed
original source/encoding metadata valid only during that owner-thread call.
The native TTY backend performs metadata planning before the global console
lock, holds that lock across the whole write and invokes no VM operation while
locked. acceptedBytes measures confirmed output; dispatchedBytes preserves the
Source Buffer/small-string counter distinction, independently bounded. Real
sync success settles the actual Writable callback in the same native frame;
the real core sync flag owns callback deferral. Async pipes still copy <=64KiB
segments and require later unique-token acknowledgement; inline completion is
rejected. Finish/destroy true means actual observed native terminal state,
never a request/tick/child-exit substitute.

Recognized native string bindings bypass live Buffer.from, using the existing
native codec before output. The exact nine Source labels take this route.
Other encodings retain the actual captured Buffer object's LIVE from lookup.
Original source/encoding identities reach the native metadata planner. Ordinary
string writes and Buffer writes are not merged into guessed counter semantics.

## One native completion lifetime

native_owner_completion.acquireNativeWake(engine) returns one owned canonical
Wake.Ref. The first acquisition creates a tagged Hub Resource and one attached
native sink; subsequent owners retain that same slot/generation. It has no
child transport dependency, thread, poll timer, blocking owner wait or guest
callback. It does not itself keep the event loop alive. Actual TTY resources
provide poll/referenced state. Its small host allocation is charged.

At Hub stop, the shared completion resource detaches its signal/Io/host sink
before task/endpoint teardown. Existing native workers own pre-retained Ref
tokens only; notify after detach is inert and release remains generation-safe.
New retain is rejected after detach. The Hub releases its reference at stopped,
after resource stop/Group cancellation. Late actual host publisher installation
is bound under the wake guard and publishes pending work. Host detachment clears
only the host sink; final detachment clears all borrowed Engine/backend inputs.
The platform facade preserves canonical Ref/Sink types and sixteen slots.

## Actual CRT retirement and explicit qualification admission

The same Pool(Wake) keeps the reviewed 64 tickets/two process-lifetime native
workers. Both slot and worker wake entitlements are retained before native fd
ownership. Submission after Engine detach makes no new retain. Workers own
only native fd/generation/attempt/packet/wake tokens; they never enter VM or
borrow Engine, Task, Group, per-Engine allocator or Io backend. An uncancellable
blocked _close is bounded native retirement, not joined/retried/replaced.

Default reserve, associate, packet.run, and nonqualified Lease IO/close remain
guarded by selected_after_independent_review=false. reserveForQualification
marks ONE ticket in the SAME pool; a trusted TTY qualifier marks its same real
Lease. submit rejects a ticket/Lease entitlement mismatch before changing close
state. beginClose copies the entitlement into the exact generation/attempt
packet, and the worker invokes runForQualification only for that admitted
ticket. claimClose still precedes actual _close; there is no second-close path.
Completed owner/detached retirement consumes actual done/result and retains a
failed numeric fd/handle association in bounded native storage without retry.

Stream's Console fd>=3 literal must set qualification_admission=qualification,
and choose reserveForQualification only from its trusted isolated qualifier.
Its fd0..2 owned DuplicateHandle/direct-close route is unchanged. Controlled
associateForQualification performs the same real _open_osfhandle transfer for
owned component controls. No global selection bit changes, duplicate pool,
fabricated descriptor or fake successful close is introduced.

## Controls and review limits

All controls are prepared and UNRUN. New native controls exercise shared wake
generation/detachment and real CRT NUL association/IO/close with default guarded
admission contrasting the explicit qualifier. Existing tty-write-string-routing
controls remain unchanged. socket-tty-controls.cjs checks the actual class graph,
same-source aliases, live native-string/default Buffer routing and real callback

Additional owned target obligations before any runtime claim: same Provider
clone plus real opaque TTY adopter, foreign opaque class rejection, wrong Engine
rejection, post-adoption read/options failure exact abandon/release, cache retry
and recursive getter rollback, GC of cached/cloned provider/adopter/handle roots,
whole >64KiB synchronous call ordering across two actual Engine owners, small
string vs Buffer failure counters using a genuinely failed native console call,
real reserved-qualified CRT close worker completion/owner detach (not a direct
packet-only result), close-ticket/Lease mismatch, and late actual host binding.
Root's bounded process owner, physical console/descriptor authorities, original
and native captures, ABI/link checks and execution admission remain required.

No compiler/formatter/AST/Node/native/generator execution, Root Main edit,
Engine/C/H edit or public activation occurs. Source review is finite source
evidence, not physical console behavior or whole node:net qualification.
