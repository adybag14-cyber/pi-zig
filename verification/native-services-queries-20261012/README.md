This remains an incomplete native Pi migration. The integrated Windows Debug/default-backend gate on pinned Zig 0.16.0 passed 91/91 tests and 189/189 build steps. Source/tool posthash verification covered 4,408/19,546 files with zero drift, and the owned process exited successfully. Those totals describe this selected execution, not unique tests or whole-Pi parity.

The gate includes actual upstream callable-tool and fork-message queries (eleven tests, all 39 query-phase host allocation indices), original executable AgentTool/context and loadout regressions (eleven), user-message delegation (eleven), typed model/auth/stream/login services (ten), original generic/assistant stream controls (seven), default CodeMode model/image consumers (eight), Chord contract/identity and SystemClone foundations (four each), Context (eleven), Resource (four), Agent allocation-marker checking (three) and native maintenance (seven).

Native Models now executes stream/complete/simple/deferred/cancel and login/logout bodies over supplied valid Provider callbacks and native credentials. The model component passed 25/25 in isolated Debug and ReleaseSafe with three strict allocation/GC probes. Original observations cover 49 cases, including three direct Assistant timing controls. Duration presence follows the actual timestamp-versus-construction-time guard; timestamps and durations are the only explicitly measured fields. Every other request, result, event, identity and error field stays exact. The native shared stream retains the previously qualified generic raw-value, queue, extractor-order and native-OOM repairs. Persistent credential files, createProvider/dynamic provider factories and full borrowed-method/class ABI remain unfinished.

Login/logout cancellation preserves the actual original mutation boundary: cancellation before mutation invokes no mutation callback; after mutation starts, the operation waits for its real commit/deletion instead of eagerly terminating. Tests use owned credential fixtures and do not read or mutate host authentication files.

Chord contract/identity bodies cover original branded local/remote/method/opaque declarations, descriptions, version binding, canonical UTF16 fingerprints and conservative structural compatibility (44 original cases including 625 schema pairs). SystemClone matches 32 original descriptor, exotic-container, iterator and retention cases. Public Clean/Default, actual Instantiate/Evaluate and complete Host record/epoch/registry lifecycle remain separate required work. No incomplete Chord package or native-default activation was enabled.

Complete failure-index partitioning and async/performance diagnosis are ongoing; this checkpoint does not claim a passing platform matrix.
