# Actual auth helper native AsyncFunction source preparation

This unit migrates the five actual async arrows returned by `auth/helpers.ts`
and the zero-Await `auth/context.ts` env method. It also provides the complete
context through `defaultProviderAuthContextAt(engine, physical_auth_context_url)`.
The actual AI module owner must pass its physical Source context file URL. The
route retains that URL, invokes the existing raw queued Graph0 import ABI with
the real builtin specifiers, and never substitutes a registry namespace or home
directory function for the imports. Graph0/Graph2, current C354/H0DBC, Promise
forwarding and runtime/application qualification remain external and unknown.

The compatibility `defaultProviderAuthContext(engine)` route still has the
legacy fileExists transport until its owner supplies the real physical URL.
Its env method is genuine. The exported `asyncArrow` adapter is deliberately
unchanged: external provider/OAuth consumers have different Source Await bodies
and cannot acquire genuine async semantics by changing a shared branding helper.
No external callsite is silently converted or claimed qualified.

The authoritative latest Source is c268154ca1171c2f9eefe75d3d7372a68aada2d5.
Retained helpers/context Source bytes are identical to the existing preserved
historical Source snapshots and to the decoded sourcesContent strings in the
accepted original 19cb published maps. Published JavaScript/maps are retained
as authority only, never used as a production implementation or bridge.
