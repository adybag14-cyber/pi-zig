# SDK-owned completion contract (source corrective)

Root authorized one SDK-only helper rather than modifying Engine/Scope or duplicating Auth/package/management unwind policies. `native_sdk_owned_completion.zig` is a host implementation leaf; it exposes no guest namespace/class/opaque stand-in and changes no VM flags on DATA.

The caller passes the REAL outcome before its local temporary roots retire:

- `finishAction(&scope, step(...))` receives an untried `anyerror!native_async_function.Action`. Initial `.thrown` is owned DATA, including a flagged/private Error. Failed-operation errors are converted while the current reason still exists. No ordinary Source outcome is latched beyond this one local scope.
- `finishValue(&scope, step(...))` receives `anyerror!JSValue`. It preserves an ordinary failed-operation reason over ordinary root-finalizer errors and rethrows that same owned reason after retirement. A successful value is released if a genuine cleanup exception replaces it.
- `finishVoid(&scope, step(...))` is for ordinary `anyerror!void` computations. Later real Source catch/finally operations retain their independent precedence.
- `finishRecorded(&scope, writer(...), realAFstate)` is for a successful body.wait/resolve/reject writer. It snapshots `body.action` BEFORE retirement, preserves recorded thrown DATA without JS_Throw or bit clearing, and does not invent a new event from the payload. A new actual cleanup exception on a recorded Await/return is a real error for the enclosing Source continuation.

For individual native/iterator root lifetimes, `Completion.initAction/initValue/initVoid` or `Completion.initRecorded` records the outcome first; call `.release(ownedValue)` in the original native deallocation order, optionally `.releaseScope(&scope)`, then matching `.finish*()` exactly once. This does not run or replace Source IteratorClose/catch/finally. A sole-owned error/token chain A-to-B-to-fatalC-to-D-to-E control exercises actual displaced-reason finalizers, and both root layouts exercise overflow. Keep a caller's explicit failing-operation generation guard before supplying an error; the helper samples/classifies no private generations and transfers initial diagnostic reason as DATA unless actual independent current-event ownership surfaces it. Use no separate `defer scope.deinit()` after transferring to these helpers. The helper consumes the caller's action/value exactly once, sets inline_count/list roots empty and retires every root, including provider inline32 plus overflow ArrayList and prompt ArrayList-only shapes. An actual prior pending/retained invocation event is observed before cleanup. Old captured diagnostic data is detached before root frees, then retired as DATA; its flag or private tag has no authority. Subsequent actual pending/new capture events are drained with the selected reason owned outside both slots. A first actual fatal promotes an ordinary completion and survives result/displaced-reason cleanup. Every pending value is taken/cleared before another owned value is freed, and final rethrow has an empty pending slot. Nonterminating/adversarial native finalizers remain outside a finite cleanup guarantee.
